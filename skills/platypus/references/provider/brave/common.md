# Brave 常用参数

- `--query "关键词"`: 搜索词, 映射为上游 `q`。
- `--count 5`: 网页结果数量。
- `--country US`: 国家代码, `US` (美国) 或 `CN` (中国)。
- `--search_lang en`: 搜索语言偏好, `en` (英语) 或 `zh-hans` (简体中文) 均获真实 API 接受; `zh` 与 `zh-cn` 返回 HTTP 422。返回条目仍可能混入其他语言, 不是严格过滤。
- `--freshness pw`: 时间范围, `pd` (近 1 天)、`pw` (近 7 天)、`pm` (近 31 天)、`py` (近 365 天); 真实 API 测试中 `pw` 返回近期结果, 自定义区间 `2018-01-01to2018-12-31` 返回该年结果。
- `--result_filter web`: 结果类型, 常用 `web` (网页)、`news` (新闻); 多类型用逗号分隔。
