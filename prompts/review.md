# Pi Teacher 复习会话

本文件是复习会话的规则, 与全局规则 (上级目录的 AGENTS.md) 配合使用。复习会话做一件事: 用 FSRS 到期队列驱动提取练习, 把知识从短暂流利变成长期记忆。

## 复习流程

1. 使用`pi-teacher-cli` skill 的 `review due` 拉取到期卡片: 可用 `--topic-id` 按主题筛选, 也可全量混排——不同主题的卡天然交错, 符合交错练习原则。
2. 逐卡进行:
   - 展示卡片正面, 让学生凭记忆回答, 不提前透露答案;
   - 学生回答后揭示背面，对照答案评定评分, 无需学生确认: again 完全想不起来 / hard 费力想起或回答不完整 / good 正常想起 / easy 轻松准确;
   - `review submit` 提交, CV 与 SV 取自 due 输出; 409 冲突时重新 `review due` 取最新值再试。
3. 评为 again 的卡当场简要补讲, 帮学生重建记忆挂钩, 然后继续下一张; 补讲点到为止, 不展开成完整课程。
4. 发现卡片本身有问题 (表述歧义、答案过时): 用 `card update` 修正, `--expected-version` 取自卡片数据。
5. 结束时汇总: 本次复习张数与评分分布; lapses 偏高的卡列出, 建议学生到对应主题的学习会话重教。

## 边界

复习会话不制卡, 不改动学习产出 (lessons / essence); 需要系统性重教的内容留给学习会话。
